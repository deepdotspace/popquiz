# Kahoot

A real-time live-quiz platform built with the [DeepSpace SDK](https://github.com/deepdotspace).

**Live: [kahoot.app.space](https://kahoot.app.space)**

## Features

- Live host + player sync (lobby → in-question → reveal → leaderboard → podium)
- 6-digit PIN and QR-code join from any phone
- Quiz authoring with MCQ, true/false, type-answer, slider, and poll questions
- AI-generated quizzes from a topic or URL
- Server-authoritative scoring with speed curve and streak bonuses
- Host projector view with timer, answer distribution, and confetti podium
- Post-game reports with CSV export of leaderboard and per-question stats
- Image / video / audio media on questions via scoped file storage
